# Financial Modelling Templates

A set of Excel templates for equity valuation and deal analysis, built by Abdullah Saeed, final-year Accounting & Finance student and CFA Level I candidate.

## What's included

### `/Three-Statement-Financial-Model`
A linked three-statement model (Income Statement, Balance Sheet, Cash Flow) with a DCF tab, forecasting free cash flow and deriving an implied valuation from WACC and terminal value assumptions.

### `/Comparable-Companies-Analysis`
A trading comparables template — benchmarks a company's valuation multiples (EV/EBITDA, EV/Revenue, P/E) against a peer group to sanity-check a standalone valuation.

### `/LBO`
A leveraged buyout model — sources & uses, debt schedule, and returns analysis (IRR/MOIC) for a private equity-style acquisition.

## How to use these

1. Download the relevant template.
2. Fill in the **Assumptions** tab with your target company's figures — everything else is formula-driven and updates automatically.
3. Check the **Checks** tab in each file — this flags balance sheet or formula errors before you trust the output.

## Formatting convention

- **Blue font** = hardcoded inputs
- **Black font** = formulas within the same sheet
- **Green font** = links pulling from another sheet
